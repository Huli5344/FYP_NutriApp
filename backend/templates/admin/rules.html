A computed target is clamped into this range before it is stored, whatever the goal and activity level would otherwise produce. The floor is the part that matters: it is what stops an aggressive weight-loss goal from recommending an unsafe intake.

Why this page has no edit controls

These values live in the server's code, which is what actually computes every target. A form here could only write them somewhere else, leaving two sets of numbers and no way to tell which one a given target came from. Changing a rule is a code change and a deploy, deliberately.
