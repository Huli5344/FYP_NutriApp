This project uses TheMealDB, not Edamam

The panel originally had a sync button that called the Edamam Nutrition API and wrote the results into a recipe table. This project does not use Edamam, and its nutrition figures come from the Health Promotion Board dataset rather than from any recipe service. Meal suggestions come from TheMealDB, whose calorie figures are estimated from the ingredient list — which is why the app labels them as estimated wherever they appear.

There is no import button here because an import would write estimated figures into the same table as published ones, and nothing downstream could tell them apart. The chain is: TheMealDB, then the cache, then the local meals above.
